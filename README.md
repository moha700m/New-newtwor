# Web Tools Runtime

Runtime and skill router for:

- Scrapling
- Patchright Enhanced
- Agent Reach

The repository provides a GitHub Actions remote runtime for network-dependent web tasks when the local ChatGPT container has outbound DNS/network or Chrome navigation restrictions.

## Layout

- `agent-skills/web-tools-runtime/SKILL.md`
- `.github/workflows/web-tools-runtime.yml`
- `runtime-requests/` on the runtime branch
