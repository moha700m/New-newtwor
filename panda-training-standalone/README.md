# Panda Training Standalone

Windows standalone training/offline screen-CV controller bridge.

- Single EXE for the end user.
- Reads a physical XInput controller.
- Mirrors controller input to a virtual Xbox 360 controller.
- Screen correction is added only to the right stick while ADS is held.
- Left stick is passed through unchanged.
- Settings are editable inside the app.
- First run can install ViGEmBus and HidHide from their official releases.

For clean controller routing, use HidHide to hide the physical controller from the game and allow PandaTrainingStandalone.exe to see it.
